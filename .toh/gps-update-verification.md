## 📋 ข้อเท็จจริงทางเทคนิค

### Traccar Update Mechanism

**วิธีการทำงาน:**
1. กล่อง GPS ส่งข้อมูลทุก 10-30 วินาที (ขึ้นกับการตั้งค่า)
2. Traccar server รับข้อมูล → update `lastUpdate` ใน database
3. WebSocket push ข้อมูลไปหน้า web real-time

**Update Interval:**
- รถกำลังเคลื่อนที่: ทุก 10-30 วินาที
- รถจอดนิ่ง: บางกล่องตั้งค่าให้ส่งทุก 1-5 นาที (ประหยัด SIM)

**Offline Threshold:**
- ถ้าไม่ได้รับข้อมูล > 5 นาที → Traccar เปลี่ยนสถานะเป็น "Offline"
