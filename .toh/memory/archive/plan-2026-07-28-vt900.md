### Root cause (ความมั่นใจสูง)
พี่โตตั้ง VT900 ให้ยิงเข้า **port 5009** → **GCP firewall drop ที่ขอบ** → packet ไม่เคยถึง Traccar → log ว่าง, `lastUpdate` ว่าง
ทุกอย่างฝั่ง Traccar ถูกต้องอยู่แล้ว ปัญหาเดียวคือ firewall

### เบาะแสเรื่อง protocol
`uniqueId` ที่ลงทะเบียนไว้ = `000143190565910` — 15 หลักนำด้วย `000` ซึ่ง **ไม่ใช่รูป IMEI ปกติ** แต่เป็นลักษณะ **BCD device ID**
→ สอดคล้องกับ **meiligao (5009)** หรือ **vt200 (5143)** มากกว่า startek (5222 = ASCII ใช้ IMEI ตรงๆ)
→ ยืนยันสัญชาตญาณพี่โตว่าลอง 5009 ก่อนถูกทาง

**⚠️ หมายเหตุ:** Traccar เก็บ protocol doc ของ iStartek ไว้ในโฟลเดอร์ `5222-startek` แต่ forum ระบุว่า iStartek ใช้ meiligao 5009 — **ต่างกันตาม firmware generation** (VT900 2G/3G รุ่นเก่า = meiligao · VT900-L 4G = startek) แผนนี้จึงเปิดทั้ง 3 port แล้วให้ device เป็นคนบอกว่าใช้อะไร
