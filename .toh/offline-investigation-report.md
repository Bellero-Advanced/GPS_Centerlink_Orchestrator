## ข้อมูลเชิงเทคนิค

### การทำงานของ Traccar GPS Server

**ข้อเท็จจริงที่พบ:**
- ทุกรถใน Traccar (206 คัน) มี `protocol = null` ในฐานข้อมูล
- แต่รถ online 95 คัน ยังทำงานได้ปกติ
- **=> Protocol field ไม่ใช่ตัวกำหนดว่ารถจะ online หรือไม่**

**วิธีการทำงานจริง:**
- Traccar **อ่าน protocol อัตโนมัติ** จาก TCP packet แรกที่กล่อง GPS ส่งมา
- Server เปิด port ทั้งหมดที่ config ไว้ (5001-5093) ตั้งแต่เริ่มต้น
- Field `protocol` ในฐานข้อมูลเป็นแค่ metadata (ไม่บังคับ, ใช้แสดงผลเท่านั้น)

**สรุป:** 
- ❌ **ไม่ใช่** ปัญหาที่ server หรือ protocol configuration
- ✅ **เป็น** ปัญหาที่กล่อง GPS แต่ละคัน (hardware, network, configuration)

## คำแนะนำการแก้ไข

### 1. รถไม่เคยออนไลน์ (63 คัน) 🔴
**ขั้นตอนตรวจสอบ:**
1. เช็คว่ากล่อง GPS ติดตั้งแล้วหรือยัง
2. เช็คว่ากล่อง GPS ตั้งค่า server IP: `traccar.gps.bellerox.com` port `5023` (GT06) หรือ port ที่ถูกต้องตาม protocol
3. เช็คว่า SIM card ใส่แล้วและมี signal หรือไม่
4. ทดสอบส่ง SMS command `SERVER#` ไปที่กล่อง GPS (ถ้ารองรับ)

**ตัวอย่าง SMS command (GT06/Coban):**
```
SERVER#traccar.gps.bellerox.com#5023#
```

---

### 2. ออฟไลน์ > 7 วัน (7 คัน) 🟠
**Action:** เปลี่ยน hardware หรือ SIM card
- กล่อง GPS น่าจะเสียแล้ว (ไม่ส่งข้อมูลมา 7-23 วัน)
- SIM card หมดอายุหรือ network ขัดข้อง
- แนะนำให้เปลี่ยนทั้งกล่องและ SIM

---

### 3. ออฟไลน์ 1-7 วัน (24 คัน) 🟡
**ตรวจสอบ:**
1. **SIM signal:** ตรวจสอบว่า SIM มี signal หรือไม่ (อาจอยู่ในจุดที่ network ไม่เข้า)
2. **GPS antenna:** ตรวจสอบว่า antenna ต่อดีหรือไม่
3. **รถจอดใต้อาคาร:** รถจอดในอาคารจอดรถ → GPS ไม่เจอดาวเทียม → ไม่ส่งข้อมูล
4. **Battery:** ตรวจสอบแบตเตอรี่รถ (ถ้ากล่องต่อแบตหลัก)

---

### 4. ออฟไลน์ < 24 ชม. (16 คัน) 🟢
**สถานะ:** รอดูต่อ — น่าจะปกติ

**สาเหตุที่เป็นไปได้:**
- รถจอดปกติในช่วงตี 1-4 เช้า
- GPS ไม่เจอดาวเทียม (จอดในอาคาร)
- กล่อง GPS อาจตั้งค่าไม่ส่งข้อมูลเมื่อรถดับเครื่อง (เพื่อประหยัด SIM)

**แนะนำ:** รอจนเช้า หากรถออกจากจอด ควรกลับมา online อัตโนมัติ
