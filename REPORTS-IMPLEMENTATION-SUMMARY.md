## 📊 Architecture Overview

```
User Request (React App)
  ↓
useReportCache Hook
  ↓
PostgreSQL daily_trip_reports (< 100ms)
  ↓ (if cache miss)
Traccar API (fallback, 2-5s)

Background (every 10 minutes):
  Worker → Traccar API → Calculate → Geocode → Cache → PostgreSQL
```
