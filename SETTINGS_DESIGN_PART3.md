## 4️⃣ จัดการหางลาก (Trailer Management)

### 4.1 จัดการหางลาก (Trailer CRUD)

**Purpose:** เพิ่ม/แก้ไข/ลบ หางลาก (trailers) ที่ต่อกับรถบรรทุก

**Data Schema:**
```typescript
interface Trailer {
  id: number;
  name: string;              // ชื่อหางลาก
  licensePlate?: string;     // ป้ายทะเบียนหางลาก
  type?: 'container' | 'flatbed' | 'refrigerated' | 'tanker' | 'other';
  brand?: string;
  model?: string;
  year?: number;
  capacity?: number;         // ความจุ (ตัน)
  length?: number;           // ความยาว (เมตร)
  width?: number;
  height?: number;
  
  groupId?: number;          // กลุ่มหางลาก
  subGroupId?: number;
  
  currentVehicleId?: number; // รถที่ต่ออยู่ปัจจุบัน
  status: 'available' | 'in-use' | 'maintenance' | 'retired';
  
  // RFID (ถ้ามี)
  rfidTag?: string;          // RFID สำหรับตรวจจับการต่อหางลาก
  
  // Insurance & Registration
  insuranceExpiry?: Date;
  registrationExpiry?: Date;
  
  notes?: string;
}
```

## 5️⃣ จัดการคนขับรถ (Driver Management)

### 5.1 จัดการคนขับรถ (Driver CRUD)

**Purpose:** เพิ่ม/แก้ไข/ลบ ข้อมูลพนักงานขับรถ

**Data Schema:**
```typescript
interface Driver {
  id: number;
  employeeId?: string;       // รหัสพนักงาน
  name: string;              // ชื่อ-นามสกุล (required)
  phone: string;             // เบอร์โทร (required)
  email?: string;
  idCard?: string;           // เลขบัตรประชาชน (13 หลัก)
  
  // License
  licenseNumber?: string;    // เลขใบขับขี่
  licenseType?: string;      // ประเภท: รถยนต์, รถบรรทุก, รถโดยสารสาธารณะ
  licenseExpiry?: Date;      // หมดอายุ
  
  // Address
  address?: string;
  province?: string;
  
  // Employment
  hireDate?: Date;           // วันเริ่มงาน
  department?: string;       // แผนก
  shift?: 'morning' | 'afternoon' | 'night' | 'rotating';
  
  // RFID
  rfidCard?: string;         // หมายเลขบัตร RFID
  
  // Assigned Vehicle
  assignedVehicleId?: number;
  
  // Safety Score (computed)
  safetyScore?: number;      // 0-100
  
  status: 'active' | 'inactive' | 'suspended';
  photo?: string;            // URL รูปถ่าย
  notes?: string;
}
```

## 6️⃣ จัดการบัตร RFID (RFID Card Management)

### 6.1 จัดการบัตร RFID (RFID Card CRUD)

**Purpose:** บันทึกบัตร RFID สำหรับระบุพนักงานขับรถ

**Data Schema:**
```typescript
interface RFIDCard {
  id: number;
  cardNumber: string;        // หมายเลขบัตร (unique)
  cardType: 'driver' | 'trailer' | 'asset' | 'access';
  assignedTo?: {
    type: 'driver' | 'vehicle' | 'trailer';
    id: number;
    name: string;
  };
  issueDate: Date;           // วันที่ออกบัตร
  expiryDate?: Date;         // วันหมดอายุ
  status: 'active' | 'inactive' | 'lost' | 'expired';
  lastUsed?: Date;           // ใช้งานล่าสุด
  notes?: string;
}
```

## 7️⃣ จัดการ User (User Management - Admin Only)

### 7.1 จัดการผู้ใช้ระบบ (System User CRUD)

**Purpose:** สร้าง/แก้ไข/ลบ บัญชีผู้ใช้ (admin only)

**Data Schema:**
```typescript
interface SystemUser {
  id: number;
  email: string;             // ใช้เข้าระบบ (unique)
  name: string;
  phone?: string;
  role: 'admin' | 'manager' | 'operator' | 'viewer';
  permissions: string[];     // ['fleet:read', 'fleet:write', 'reports:read', ...]
  
  // Access Control
  allowedDeviceIds?: number[];     // จำกัดเฉพาะยานพาหนะที่เห็น
  allowedGroupIds?: number[];      // หรือกลุ่มที่เห็น
  
  // Session
  lastLogin?: Date;
  loginCount?: number;
  
  status: 'active' | 'inactive' | 'pending';
  invitedBy?: number;        // user ID ที่เชิญ
  createdAt: Date;
}
```

**Role Definitions:**
```typescript
const ROLES = {
  admin: {
    label: 'ผู้ดูแลระบบ',

    label: 'ผู้จัดการ',
    permissions: [
      'fleet:read', 'fleet:write',
      'reports:read', 'reports:export',

      'maintenance:read', 'maintenance:write',
    ],
    description: 'จัดการยานพาหนะ รายงาน แจ้งเตือน',
  },
  operator: {
    label: 'ผู้ปฏิบัติงาน',
    permissions: [
      'fleet:read',
      'reports:read',
      'alerts:read',
    ],
    description: 'ดูข้อมูลยานพาหนะและรายงาน',
  },
  viewer: {
    label: 'ผู้ดู',
    permissions: [
      'fleet:read',
      'map:read',
    ],
    description: 'ดูแผนที่และตำแหน่งยานพาหนะเท่านั้น',
  },
```
